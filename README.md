Personal portfolio website for Ammar Sohail, a backend engineer specializing in distributed systems, production engineering, and agentic software-development workflows.

## Highlights

- Backend and distributed-systems experience
- AI-augmented engineering capabilities
- Professional work at Careem and Airlift Technologies
- Selected professional and personal projects
- Technical writing and downloadable resume
- Responsive light and dark themes

## Technology

- React
- JavaScript
- Sass
- Lottie animations
- Font Awesome

## Run locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production build

```bash
npm run build
```

The optimized static website is generated in the `build` directory.

## Content and configuration

Portfolio content is maintained in:

```text
src/portfolio.js
```

Global colors are configured in:

```text
src/_globalColor.scss
```

SEO metadata is configured in:

```text
public/index.html
```

## Deployment

The website can be deployed to Vercel by importing this GitHub repository and using:

```text
Build command: npm run build
Output directory: build
```

Vercel will automatically deploy new versions when changes are pushed to the connected production branch.
